# Swahili glossary — Ruaha 360

Compiled 2026-09-29 for the draft Swahili in `src/i18n/sw/common.json`. 176 terms: 96 verified, 80 unverified.

**Verified** means a Tanzanian-context source, or two independent sources, attest the term, and the evidence column says what was seen. **Unverified** means the term is a candidate with no Tanzanian source. A native reviewer should check those first. Government hosts (`.go.tz`, `.co.tz` energy utilities) refused connections from the research environment, so some evidence is a search snippet or a Tanzanian press article quoting the body, and is labelled as such.

## Style rules used for the draft

- **Tone.** Neutral and respectful, second person singular addressed through verb prefixes (u-/ni-) rather than 'wewe'; 'tafadhali'/'naomba' for politeness (MS Kiswahili guide: 'best to use a neutral tone that is respectful by using words such as Tafadhali/naomba'; 'wewe ... not normally used except for identification or emphasis'; 'Sasa umeunganishwa kwenye Wavuti'). Tanzanian apps address the user directly with possessive 'yako' ('akaunti yako', 'Weka namba yako ya siri', Vodacom M-Pesa/Selcom/CRDB) and short instructions. MS: short, simple, complete sentences; no slang or jargon. NIDA forms use third-person 'Mwombaji anatakiwa ...' (the applicant must), an official register not suited to a farmer app.
- **Buttons.** Bare imperative stem, no ku-. Every Tanzanian button/instruction string observed is imperative: Ingia, Jisajili, Fungua Akaunti, Wasilisha, Tafuta, Pakua, Tuma, Weka, Chagua, Ingiza, Thibitisha, Bonyeza, Endelea, Zuia, Ongeza, Rudi nyuma (NIDA, CRDB, Selcom, Vodacom docs, M-Pesa/Mixx/CRDB app-store text). MS guide text says 'translate a verb as a verb (infinitive form)' but every example it gives is a bare imperative ('Simamia Vifaa vya ziada', 'Chomeka Jedwali', 'Hifadhi mabadiliko', 'Bofya hapa ili kuanza', 'Thibitisha ugeuzaji ...', '/A Jaribu tena'), none with ku-. Vodacom docs also use infinitive after Chagua ('Chagua 1 "Ndio" kukubali', 'Ingiza 1 Kuthibitisha'). Use imperative for buttons; ku- infinitive only inside sentences.
- **Password.** Neno la siri (NIDA eonline: 'Neno la Siri', 'Hakiki Neno la Siri', 'Umesahau Neno la Siri?'). Alternatives NOT seen on Tanzanian user-facing pages: 'nenosiri'. MS TZ guide sample uses 'nywila' ('Andika nywila kuingia kwenye server'). PIN is separate: 'PIN' or 'Namba ya siri' (Vodacom, CRDB, Airtel Tanzania). Phone number: 'Namba ya simu' (NIDA, Vodacom, Selcom) with 'Nambari ya simu' also on CRDB.
- **Currency.** Tanzanian shilling. MS TZ guide: name 'Tanzanian Shillings', symbol 'Tshs.' placed before the value ('Tshs.2,000.50'), thousands comma, decimal point. Tanzanian press (Mwananchi) writes 'Sh340', 'Sh27,000', 'Shilingi bilioni 150' (Chanzo). No source seen for 'TZS' on a Tanzanian consumer UI (the repo's admin field uses TZS). For farmer-facing text prefer 'Sh 5,000' or 'TZS 5,000' consistently; not decided by any source. Per product rule the incentive is never labelled indicative and never called earnings/wallet/balance/payment.
- **Dates.** MS TZ guide: Gregorian, week starts Monday (Jumatatu); short date dd/MM/yy ('17/03/11'), long 'dd MMMM, yyyy' ('17 Machi, 2011'); leading zeros; month names Januari, Februari, Machi, Aprili, Mei, Juni, Julai, Agosti, Septemba, Oktoba, Novemba, Disemba; days Jumatatu, Jumanne, Jumatano, Alhamisi, Ijumaa, Jumamosi, Jumapili. Time: MS says computers use am/pm-style (not Swahili clock) 'Kiswahili time is counted differently ... computer users currently use the am/pm system'. CAUTION: nida.go.tz shows office hours '01:30 asubuhi - 09:30 alasiri' which is Swahili clock (six hours offset from 07:30-15:30), so never mix; use the 24-hour or am/pm clock explicitly.
- **Numbers.** Thousands separator comma, decimal point, as used in Tanzanian press ('megawati 1,363.94', 'kilowati-saa milioni 1,137.84', 'megawati 1,872.05') and MS TZ guide table ('1,200,500', '3.5'). NOTE the MS guide contradicts itself: its Punctuation section says 'In Kiswahili a comma is used' for decimals while its Digit Groups table says decimal '.'; Tanzanian press practice follows the table. Phone: MS TZ guide domestic mobile is 10 digits with leading 0 in groups, international +255; NIDA shows '0232210500'. Units: keep SI symbols (kW, kWh, ha, kg); spell 'kilowati-saa', 'megawati' in prose (Mwananchi hyphenates 'kilowati-saa'). MS: digits for measurements, percentages, currency, numbers above 20.

## Editorial decisions

Where sources disagree, or none exists, the draft follows these choices. Each is open to the reviewer.

- **Verify vs confirm.** Sources split: hakiki (NIDA, NBS, TCRA) against thibitisha (CRDB, Vodacom, Selcom). One word each so a screen never mixes them: **Verify = Hakiki**, verified = imehakikiwa, unverified = haijahakikiwa; **Confirm = Thibitisha**.
- **Password.** neno la siri (NIDA). Not "nywila" (Microsoft sample only) and not "nenosiri" (not seen on any Tanzanian page). Temporary password = neno la siri la muda.
- **Buttons.** Bare imperative, no ku-: Ingia, Hifadhi, Endelea, Tuma. Every Tanzanian UI string observed is imperative. The Microsoft guide says infinitive but its own examples are imperative.
- **Indicative price.** **Not "bei elekezi".** In Tanzanian usage it means an official price set or published by the government or a regulator (cashew, fertilizer), so it would make a programme catalogue price look regulated. Use "bei ya makadirio" (estimated price) and always keep the sentence "si nukuu ya bei" (not a quotation). Reviewer to confirm.
- **Estimate.** makadirio / imekadiriwa, always. "Not a measurement" = "si kipimo".
- **Opportunity.** **fursa**. It does not imply a completed sale. Never mauzo (sales) or mkataba (contract). "Not a sale, a delivery or a payment" is written out in full each time.
- **Survey incentive.** **motisha** (incentive), attested in Tanzanian usage for incentives generally; use for survey respondents is not attested. Voucher = **vocha** (attested for Ministry of Agriculture subsidy vouchers). "Fixed cash amount" = kiasi maalum cha fedha taslimu. Never malipo (payment), mapato (income), mshahara (salary), salio (balance), pochi (wallet), zawadi (prize), posho (allowance) or ruzuku (grant). Enforced by a test.
- **Land area.** planted area across cycles = "Jumla ya eneo lililopandwa katika mazao yote". Never a phrase that means land area. Crop cycle = msimu wa zao (composed; "mzunguko wa mazao" means crop rotation, so avoid mzunguko).
- **Location units.** kaya (household), mkuu wa kaya, kijiji, kata, wilaya, mkoa: attested in NBS and NIDA usage.
- **Field officer.** "Afisa Ugani" is the government agricultural-extension role, which this programme role is not. Use "Afisa wa uwandani" (composed, unverified).
- **Sign out.** Toka (seen on a Kenyan-owned Tanzanian news platform) against Ondoka (Microsoft sample). Toka chosen, unverified.
- **Small words.** Yes = Ndiyo, No = Hapana (CRDB); phone number = Namba ya simu (NIDA, Vodacom, Selcom); QR code = msimbo wa QR; scan = Skani.
- **Names and symbols.** Ruaha 360, Ruaha Energy, kW, kWh, kg, ha, TZS, QR, PIN and GPS stay as written. Units are SI symbols in figures.
- **Tone.** Polite and direct. Second person singular by verb prefix (u-, ni-), possessive "yako". No "wewe" except for emphasis. "Tafadhali" only where a request needs softening.

## Known disagreements for the reviewer

- Month names: Microsoft (Tanzania) "Disemba"; CLDR (what the app displays) "Des". Decided: the app uses CLDR via `Intl`, so nothing is typed by hand.
- Irrigation: the DB seed says "Umwagiliaji"; AGROVOC says "kutia maji". The DB seed is unchanged.

- Mwananchi is a Nation Media Group (Kenyan-owned) platform; its account-menu strings (Ingia/Toka/Jisajili) may be shared with Kenya's Taifa Leo.
